## ⚙️ 주요 기능

### 1. 데이터 정제 (`1_데이터_정제.py`)
- **CSV 파일 업로드:** 구글 설문지 응답 데이터(`survey_raw.csv`) 업로드
- **열 이름 표준화:** 질문 항목을 짧고 명확한 열 이름(`타임스탬프`, `성별`, `학년`, `소속단과대학`, `AI사용시간`, `Q1~Q6`, `서술형`)으로 변경
- **중복 및 이상치 처리:**
  - 타임스탬프 제외 동일 응답 중복 제거
  - 사이드바 슬라이더를 이용한 AI 사용 시간 이상치 허용 범위 설정 (분 단위)
- **표기 통일 및 분류:**
  - 학년: 숫자 형태로 통일
  - 단과대학: 주요 5개 단과대학(인문, 사회과학, 경제통상, 경영, 사범) 및 기타로 분류
- **결측치 및 역문항 처리:**
  - 결측치 '그대로 두기' 또는 '행 삭제' 선택
  - 학업 정직성 역문항 점수 재계산 ($Q6R = 6 - Q6$)
- **결과 저장:** 정제 기록 확인 및 정제된 CSV 파일 다운로드, `st.session_state` 저장

### 2. 그래프 분석 (`2_그래프_분석.py`)
- **요약 지표:** 유효 응답 수, 평균 AI 사용 시간, AI 윤리의식 평균 제시
- **정제 전후 비교:** 단과대학별 응답자 수를 가로 막대 그래프로 나란히 비교
- **4가지 영역 탭 시각화:**
  1. **응답자 구성:** 성별, 학년, 단과대학 분포
  2. **문항별 평균:** Q1~Q6R 항목별 평균 점수
  3. **집단 비교:** 학년별/단과대학별 인원수 및 문항별 평균 점수 표
  4. **사용 시간과 점수:** AI 사용 시간과 overall 문항 평균의 상관관계 분포
